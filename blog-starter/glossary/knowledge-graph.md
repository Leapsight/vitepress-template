# Knowledge Graph

A **knowledge graph** records things and the relationships between them as
nodes and edges, each with a type. On this blog every post, author and glossary
term is a node, and each link between them is an edge — usually a
[typed edge](./typed-edge).

Because the graph is built from the markdown at build time, it stays in step
with the content: there is no second copy to maintain.
