# Typed Edge

A **typed edge** is a link in the [knowledge graph](./knowledge-graph) that
carries its relationship: `schema:about`, `schema:mentions`, or any predicate
the site's ontology declares. In markdown it is a normal link with a
`{rel="…"}` attribute after it.
